# docura_ou_travessura
Doçura ou Travessura

🎃 Virtual Trick or Treat 🍬
Bem-vindo ao Virtual Trick or Treat, um projeto web interativo e assustador desenvolvido para celebrar o Halloween de forma digital! Este repositório está configurado para correr diretamente no GitHub Pages.

👻 Como Funciona?
O site coloca os visitantes perante a escolha clássica do Halloween:

🍬 Doçura: Um botão que permite apoiar o projeto através de um donativo seguro via PayPal.

🕷️ Travessura: Um botão que despoleta uma de várias surpresas aleatórias em JavaScript.
